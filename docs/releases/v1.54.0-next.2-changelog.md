## @backstage/cli-module-build@0.1.7-next.0

### Patch Changes

- bb98419: Package preparation for publishing validates TypeScript configuration schemas strictly, preventing invalid schemas from being published. Other build and bundle paths report schema errors as warnings.
- Updated dependencies
  - @backstage/config-loader@1.11.2-next.0

## @backstage/cli-module-config@0.1.6-next.0

### Patch Changes

- bb98419: The `--strict` flag for `config:check` now treats TypeScript configuration schema errors as fatal. The same flag is now also available for `config:schema`.
- Updated dependencies
  - @backstage/config-loader@1.11.2-next.0

## @backstage/config-loader@1.11.2-next.0

### Patch Changes

- bb98419: Added an `onSchemaError` callback that allows callers to report TypeScript configuration schema errors and continue loading. The callback receives a `ConfigSchemaError` containing the source package and underlying cause. Without a handler, schema errors are thrown.
